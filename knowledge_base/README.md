# 反诈知识库（待接入 App）

**目标**：为视频守护的本地/联网风险判断提供可持续人工维护、带来源、可回滚的事实与话术模式。此目录目前是**资料和结构化知识的起点**，不会自动进入 v1.0.0-b3 APK，也不改变 App 现有判断。

## 权威归属与审核门槛

- `sources/`：每条投稿的来源档案。包括尚不可读取和未核验的材料。存档链接**不等于认可内容**。
- `patterns/`：未来经过审核的短小反诈知识卡。应包含可观察的语音话术、诈骗步骤、反例、风险解释、建议及可追溯来源。
- `schema/`：用于避免自由文本无约束入库的 JSON Schema。
- **唯一进入正式识别的条件**：知识卡状态为 `approved`，含有效来源引用、人工 `reviewed_by`、`reviewed_at`，并通过离线样本的误报/漏报回归；来源 `pending_content` 或 `pending_human_approval` 不得直接提升为正式知识。
- 参考材料可包含官方通报、权威媒体和经核验的案例；微信、自媒体的来源可信度须单独核查。发布日期不等于资料收集日期。
- 不采集/公开手机号、银行卡号、身份证号、真实对话音频等个人敏感资料；保持短事实摘要与原始 URL，不整篇复制有版权的文章。

## 每次用户提交新材料的处理

1. 建立新 `SRC-YYYYMMDD-NNN` 条目：原始 URL、投稿日、标题/发布者（无法核实时为 null）、访问状态和审核状态。
2. 能读取时摘录事实性结论：诈骗类型、话术、诱导动作（转账/扫码/下载/共享屏幕）、出处和不确定性；同类多篇归并去重。
3. 人工核对官方来源、时效、是否误读；给每个重要风险信号准备对应的正常场景反例，防止以单个关键词判定诈骗。
4. 通过审核后另行生成 `patterns/` 知识卡；`approved` 内容才允许被打包进本地检索或同步至联网检索。保留可追溯版本并支持撤销。
5. 每次发布前对有诈骗话术、无诈骗话术和容易混淆的话术进行回归，分别统计准确率、召回率和漏报/误报，避免宣称绝对准确。

## 待接入 App 的建议（**尚未实现**）

- 将 `approved` 卡片构建成小体量 JSON/SQLite FTS5 检索包；输入来自本地 ASR 文本，优先做轻量 BM25/关键词候选召回，再附带 1–3 条证据卡供本地 Qwen3.5-2B 综合判断。
- 联网模式优先检索同一套审核通过的卡片，实时网页只能作为补充证据；未经核验网页不能改变库内权威内容。
- 将知识库版本号、构建时间、内容校验值与 App 版本分离；离线包升级必须进行完整性验证，失败回滚。更新服务须考虑签名及安全通道。
- 风险提示按“疑似诈骗 + 可观察证据 + 建议核验”表达；单独一条风险词不是诈骗结论。
