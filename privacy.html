一、我们处理的信息

麦克风录音与风险分析

打开应用不会自动开始守护。您点击「开始守护」，完成应用内同意、权限及所选模式的准备后，应用才可能在符合采样条件时录制手机麦克风声音片段。当前实现约每个采样周期录音55秒；受保护应用须在前台、屏幕可用，并通过外放路由等条件检查。锁屏、熄屏或检测到耳机、蓝牙等外接播放路由时不录音。

出声资格通常依据设备全局音频播放状态，应用不能判断声音来自哪个应用；在默认抖音范围内，已确认的全屏直播也可独立满足页面资格，不要求该播放信号。麦克风可能录到静音、手机外放或附近谈话、电视声。

  • 本地模式：语音识别和风险判断在手机本机完成，录音和识别文字不离开手机。录音仅暂存在手机缓存，分析完成、取消或失败后删除；应用不持久保存识别文字或模型输出原文。
  • 联网增强模式：只有您主动切换并再次同意后，录音才会直接发送至腾讯云语音识别；识别文字和您添加的判定规则会发送至腾讯云 TokenHub 进行风险判断。请求使用您自行配置的账号凭据。

应用使用情况与已安装应用列表

应用在本机读取「使用情况访问权限」信息，以判断当前前台是否为您选择的受保护应用；该信息不上传、不长期保存。首页创建及构建守护范围列表时会查询手机上可启动的应用，可能发生在您首次同意之前；打开守护范围页面时也会重新查询。查询结果用于本机展示和匹配，不上传。应用不申请读取全部安装包的权限；首次未设置范围时会默认勾选识别出的常用视频平台和视频类应用，全部取消选择后回到默认抖音范围。

检测统计与通知

应用可在本机保存检测时间、风险等级或失败状态、固定类别和实际规则版本，不包含录音、识别原话或原因正文。统计按手机日期滚动保留最近六个日历月，详情最多20,000条；达到上限时移除最旧详情。应用在打开、查看报告或写入时清理过期数据，不保证到期时后台立即删除。应用没有单独清空统计的界面入口。

中高风险提醒可能在系统通知栏显示经过安全处理的原因短文。应用不把该正文写入自己的数据文件，统计记录也不包含正文；通知可由 Android 系统保留，直到您或系统清除。

意见反馈

只有您填写反馈并确认发送后，反馈文字以及手机品牌、型号、Android 版本和应用版本才会通过飞书开放平台发送给开发者。请勿填写身份证号、银行卡号、密码等信息。应用在本机只持久保存上次成功发送时间以避免短时间重复发送；未发送的输入可能在页面重建时临时恢复。

已发送到反馈群的消息没有应用控制的自动到期删除机制。您可以联系上方邮箱申请处理，但目前没有承诺的保留期限或答复时限。撤回应用内同意不会自动删除已经发送的群消息。

云端账号凭据

联网增强模式使用您自行填写的腾讯云 SecretId、SecretKey 和 TokenHub API Key。凭据以 Android Keystore 加密后保存在本机，不随备份或换机迁移，也不发送给开发者；相应服务鉴权所需的信息会随请求发送给该服务。选择联网增强模式后，即使尚未开始录音，打开应用或相关页面也可能查询您账号的免费额度和模型状态。建议使用权限受限的子账号密钥，并在服务控制台关闭后付费或按量付费。

本地模型下载

轻量版只有在您进入本地模式设置并主动点击「一键下载」后，才从当前配置的 hf-mirror.com 地址下载模型，并可能跟随该站点的 HTTPS 重定向。下载站点及实际承载文件的站点会收到常规网络请求信息，例如 IP 地址、请求时间、文件路径和续传范围；应用不会随下载发送录音、识别文字、检测记录或云端凭据。镜像及实际承载站点各自适用的隐私政策请以您访问时的实际站点说明为准，本政策不提供未经核实的镜像专属政策链接。

下载内容是固定版本的 SenseVoiceSmall INT8 语音识别模型、Qwen3.5-2B Q4_0 风险判断模型和词表，应用校验版本、大小及 SHA-256，不下载可执行代码。模型保存在本机不参与备份的私有目录；模型准备完成后，本地分析可离线进行。完整离线版从安装包准备模型，无需此下载步骤。

规则更新

规则更新来源当前尚未配置，应用目前不发起规则更新请求。规则更新功能启用后，手动检查或您主动开启的约每月检查只会下载经过审核和签名的规则包，不会上传录音、识别文字或检测记录；自动检查默认关闭。届时会按实际启用的来源补充其信息。更新失败时沿用现有规则。

设置与同意记录

应用在本机保存守护范围、采样间隔、您添加的判定规则、工作模式及切换信息、规则更新偏好和配置进度等设置。应用也在本机保存同意说明版本、范围、时间、随机记录标识及有效或撤回状态；该标识不上传。撤回同意会使原记录失效，重新同意会生成新标识。

二、权限

  • 麦克风：录取声音片段；拒绝后无法守护。
  • 使用情况访问：判断前台应用；拒绝后无法守护。
  • 通知：显示守护状态和风险提醒；拒绝后无法守护或查看状态、提醒。
  • 悬浮窗：高风险时尝试显示红色边框；开始前未授予会阻止开始，运行中丢失时守护和通知仍保留，但红框不可用。
  • 网络及网络状态：模型下载、联网增强分析和额度查询、反馈发送，以及未来配置来源后的规则更新；联网操作无法完成时，本地模式在模型准备好后仍可离线分析。
  • 麦克风类型前台服务：守护运行时保持录音能力并显示常驻通知；缺少该能力无法守护。

麦克风和通知是系统运行时权限；使用情况访问与悬浮窗需在系统设置中开启。网络、网络状态和前台服务由安装包声明。您可在系统设置管理可撤销权限；撤回应用内同意不会替您关闭系统权限。

三、第三方服务与本地组件

  • 腾讯云语音识别：联网增强模式下接收录音片段。参阅腾讯云隐私保护声明和语音识别服务条款。
  • 腾讯云 TokenHub：联网增强模式下接收识别文字和您添加的判定规则。参阅腾讯云隐私保护声明和TokenHub 服务条款。不同模型的适用数据处理安排仍须按实际使用情况核实。
  • 飞书开放平台：您主动发送反馈时接收反馈内容与设备、版本信息。参阅飞书隐私政策。
  • hf-mirror.com 及 HTTPS 重定向后的实际模型文件承载站点：轻量版主动下载模型时接收网络请求信息。请在访问时查看实际站点适用的政策。

按当前运行依赖和随包代码清单，应用未集成广告、统计分析或推送类第三方 SDK。腾讯云和飞书通过 HTTPS 直接访问，未接入其 Android 客户端 SDK。本地推理使用 sherpa-onnx（含 ONNX Runtime）、llama.cpp/llama-server、GGML 等组件；本机推理通信使用手机回环地址，不向外部服务器发送分析内容。相关组件许可清单仍待开发者最终核对。

应用没有自建云端服务器，不会自动向开发者发送录音、识别文字或检测记录；您主动提交的反馈会发送给开发者。第三方服务的数据留存、处理地域及删除规则以各服务实际适用的政策为准，删除手机上的临时文件不代表第三方数据已删除。

本政策网页为静态页面，不运行脚本、不含统计追踪代码、不自动向应用或开发者发送数据，也不提供数据提交表单。页面中的第三方政策链接由您主动点击后打开；访问托管网页或第三方网站时产生的网络请求信息由相应网站按其规则处理。

四、您的选择与权利

  • 停止守护：在首页点击「停止守护」，停止后续录音和分析。
  • 撤回同意：进入「使用说明与设置 → 使用与隐私」，点击「撤回同意（停止守护）」并确认「确定撤回」。成功撤回后会阻止新的录音和分析；下次开始须重新阅读并同意，重新同意不会自动开始守护。
  • 删除本机数据：通过系统设置清除应用数据或卸载应用，可删除本机统计、设置、凭据密文和模型文件；之后可能需要重新准备模型和录入凭据。应用内没有单独清空统计的按钮；凭据设置页可清空凭据，判定规则页可清空用户规则。撤回同意本身不会删除这些数据。
  • 已发送的数据：应用无法撤回已发送给腾讯云的数据或已发送的反馈，其处理依相应服务规则进行。
  • 联系开发者：如需就个人信息提出查询、更正或删除申请，请发送邮件至 video_guardian@126.com。目前没有承诺的答复时限。
